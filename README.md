# Limpieza de datos

Práctica de Minería de Datos para aprender a identificar valores faltantes, registros duplicados y formatos inconsistentes antes de entrenar un modelo.

## Archivos

- `practica.py`: carga y exploración del dataset.
- `dataset_con_errores.csv`: datos originales de la práctica.

## Cómo ejecutar

Instalar las librerías:

```bash
pip install pandas numpy
```

Ejecutar la práctica:

```bash
python practica.py
```
